# Trading Journal (Static Version)

This repository now includes a deployable static app built with only:
- HTML (`index.html`)
- CSS (`styles.css`)
- JavaScript (`script.js`)

## Run locally

Open `index.html` in your browser.

## Deploy on GitHub Pages

1. Push these files to your repository default branch.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose:
   - **Source:** Deploy from a branch
   - **Branch:** `main` (or your branch) and `/ (root)`
4. Save and wait for the Pages URL to be published.

## Notes

- Trade data is stored in browser `localStorage`.
- No backend is required.
